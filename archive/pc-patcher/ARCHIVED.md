# Archived: patching the Android game from a PC

**No longer maintained (since 2026-10-28).** Use the WF Revival Patcher app on the device instead
([guide](https://wf-revival.silentanarchist.com/guides/phone), [releases](https://github.com/silentanarchist/wf-revival-mod/releases)).
It runs the same patching code on the device itself, needs no PC or cable, and is the only way that
gets new patching features (for example the start-up picture from Patcher 0.4.2).

These scripts and `LemonPatch.exe` (built from the same patching code, downloaded by
`tool/get-tools.ps1` from a pinned commit) are kept as they were for reference and for the source
offer in `THIRD-PARTY-NOTICES.md`. They may still work, but nothing here will be updated or fixed.
